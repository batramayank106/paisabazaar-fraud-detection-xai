# Changelog

- Complete data cleaning pipeline with sentinel value detection
- 15+ engineered financial risk features
- Fraud label engineering from domain rules
- 6 ML models: Logistic Regression, Decision Tree, Random Forest, XGBoost, LightGBM, CatBoost
- Class imbalance handling with class weights, SMOTE, SMOTEENN

- Comprehensive EDA with 15+ interactive visualizations
- Statistical analysis: hypothesis testing, ANOVA, chi-square, effect sizes
- Model evaluation: ROC, PR, calibration, lift/gain curves, threshold analysis
- Production-quality codebase with modular src/ package
- Docker support
- Full documentation and README
